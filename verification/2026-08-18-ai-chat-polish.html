In-App AI Chat Polish — Manual Verification

Spec: docs/specs/2026-08-18-in-app-ai-chat-polish.md

Date: 2026-08-18. Run after pnpm db:migrate (migration 011) is applied and both backend + frontend are running.

What to verify: streaming response, tool-call chips, server-backed history, copy/regenerate/cancel/export buttons.

Scenario 1: Streaming response

Action: Open /ai-workspace. Ask a question in the composer.
Expect: Answer text appears progressively (not all at once). Each token is appended as it streams.
Verify: Open DevTools Network tab. The POST /api/crm/ai/chat request should be text/event-stream with multiple event: chunk frames.
(unmarked)

Scenario 2: Tool-call chip

Action: After a streaming answer, enable the "Tampilkan tool chips" checkbox (top-right).
Expect: A "hybridRetrieval" chip appears above the answer with "0 result(s)" (or more if chat-A KB matches). Click the chip to expand and see the JSON input.
(unmarked)

Scenario 3: Server-backed history

Action: Ask 3 questions. Reload the page (Ctrl+R).
Expect: The left sidebar shows the 3 questions in newest-first order. Clicking a row restores the question into the composer.
Verify: SELECT count(*) FROM ai_chat_history; in psql returns 3 rows.
(unmarked)

Scenario 4: Copy + Regenerate

Action: After a streaming answer completes, click "Copy" then paste somewhere. Click "Regenerate" — the previous answer is replaced with a new stream.
Expect: Copy puts the answer text on the clipboard. Regenerate re-asks the same question and shows new chips + answer.
(unmarked)

Scenario 5: Cancel mid-stream

Action: Ask a question. While the answer is still streaming, click "Cancel".
Expect: The stream stops (partial answer remains in the UI). The composer becomes available again.
(unmarked)

Scenario 6: Export to Markdown

Action: After at least 2 questions, click "Export" (top-right). Paste into a markdown viewer.
Expect: Both questions appear as ## headings with their answers and confidence scores.
(unmarked)

Done

All 6 scenarios pass = polish verified. Any failure = block release and investigate.
